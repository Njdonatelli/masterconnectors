FAQ

Is the open-source version going away?
No. OpenOSINT stays free and MIT-licensed. Cloud is an additional hosted option, not a replacement.

What data sources are included?
See What's Included above. All final sources and quotas are confirmed at launch, not on this page.

Do you offer people search or breach lookups?
No. OpenOSINT Cloud is scoped to infrastructure intelligence only — IP geolocation, ASN/ISP, proxy/VPN/Tor detection, IP reputation, DNS, subdomains, domain/RDAP data, and news/geo signal. See the Acceptable Use Policy.

When does it launch?
When the waitlist shows enough demand. Joining helps us decide.

Can I self-host instead?
Yes — the framework is MIT-licensed. See the main OpenOSINT docs for the CLI, web UI, and MCP server you can run yourself today.

DATA SOURCE ATTRIBUTION

IP geolocation and ASN data via ipinfo.io. Proxy/VPN/Tor and threat-score data sponsored by IP2Location.io. Additional host and service signal via Shodan where included in a given plan. Each provider's data is used under its own terms.
