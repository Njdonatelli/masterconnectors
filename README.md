## Installation

### Antigravity CLI (`agy`)
Install the plugin directly using the Antigravity CLI:
```bash
agy plugin install /path/to/masterconnectors/plugins/masterconnectors
```
Or run the automated install script:
```bash
python3 scripts/install_plugins.py
```

### Claude Code (`claude`)
Add the marketplace and install the plugin:
```bash
claude plugin marketplace add /path/to/masterconnectors
claude plugin install masterconnectors@masterconnectors
```
